KBE aliasing summary
----------------------------------------
  hawkes_kbe_engine.py used natural_k(z1,z2)=floor((z1+z2-2)*K/(2*Z))
  as its state index.  This function is MANY-TO-ONE: multiple (z1,z2)
  pairs with the same z1+z2 map to the same k value, so the KBE result
  is identical for all cells on each anti-diagonal.

  Required fix:
    state_idx = (z1 - 1) * Z + (z2 - 1)   # range 0..Z²-1
  This preserves the full (z1, z2) resolution so that:
    - sell-side events index into mu[e, z1-1, xi]  (ask depth)
    - buy-side  events index into mu[e, z2-1, xi]  (bid depth)
  and P(ask up | z1, z2) is correctly asymmetric in z1 vs z2.


MC warm-start details
----------------------------------------
  The Hawkes calibration fits mu[e,d,xi] per excitement bin xi.
  At xi=0 (cold start) mu is near zero for most cells because
  the empirical data always has some residual excitement.
  Fix: initialise A[e] = mu[e,d,xi_avg] / (beta[e,d,xi_avg] - alpha)
  then run T_burnin seconds of burn-in before measuring.
